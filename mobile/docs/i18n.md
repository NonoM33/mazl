# Traductions de l'app MAZL

L'interface existe en **français** (langue de référence des textes), **anglais**
(repli quand le téléphone parle une langue que l'app ne connaît pas), **hébreu**
(de droite à gauche), **espagnol** et **russe**. La langue suit celle du
téléphone ; les réglages permettent d'en choisir une autre (« Langue »).

## Où vivent les textes

```
lib/l10n/fragments/<feature>/app_fr.arb   ← on écrit ici (référence + descriptions)
lib/l10n/fragments/<feature>/app_en.arb   ← une traduction par langue
lib/l10n/app_<langue>.arb                 ← ASSEMBLÉ, ne pas éditer
lib/l10n/generated/                       ← GÉNÉRÉ, ne pas éditer
```

Après chaque modification d'un fragment :

```bash
dart run tool/l10n.dart
```

Dans un widget : `Text(context.l10n.chatComposerHint)` (`import 'package:mazl/l10n/l10n.dart'`
ou le chemin relatif `../../../../l10n/l10n.dart`).

## Règles d'écriture

| règle | pourquoi |
|---|---|
| Clé en camelCase, préfixée par le nom du fragment : `chatComposerHint`, `coupleSpaceTitle` | une clé = un propriétaire, aucun conflit entre features |
| Chaque clé française a un `@clé.description` : où le texte apparaît, ce qu'il fait, la longueur disponible si elle est serrée | le traducteur ne voit pas l'écran |
| Une phrase entière par clé, avec des paramètres `{name}` ; jamais de morceaux recollés (`'Bonjour ' + nom`) | l'ordre des mots change d'une langue à l'autre |
| Pluriels en ICU : `{count, plural, =0{Aucun like} =1{1 like} other{{count} likes}}` | le russe a 4 formes (`one`, `few`, `many`, `other`), l'hébreu 3 (`one`, `two`, `other`) |
| Paramètres typés dans `placeholders` (`int`, `String`, `DateTime`) | gen-l10n vérifie les appels |
| `mazl+` et `MAZL` ne se traduisent pas | noms de marque |
| Pas de compte de démo, d'adresse e-mail, de jeton dans un texte | un test le refuse |

Fragments communs (`common`) : `commonCancel`, `commonContinue`, `commonRetry`,
`commonClose`, `commonBack`, `commonSave`, `commonDelete`, `commonRemove`,
`commonSkip`, `commonSee`, `commonShare`, `commonReport`, `commonOk`,
`commonLater`, `commonToday`, `commonYesterday`, `commonNotSpecified`,
`commonLoadError`, et les erreurs `error…` (voir plus bas).

### La voix, langue par langue

- **Français** : vouvoiement partout (`test/features/design/vouvoiement_test.dart`
  lit aussi les ARB). Seuls les brouillons de premier message (`icebreaker…`)
  tutoient : c'est le membre qui parle à un autre membre.
- **Anglais** : simple et direct, « you ».
- **Hébreu** : **formes neutres**, jamais accordées au genre : infinitif ou
  tournure impersonnelle (« להוסיף תמונה », « יש להזין שם », « אפשר לנסות שוב »).
- **Espagnol** : « tú ».
- **Russe** : « Вы » (avec majuscule).

## Dates, heures, nombres, prix

- `final locale = context.l10n.localeName;`
- Dates : squelettes `intl`, jamais de motif écrit à la main :
  `DateFormat.MMMMEEEEd(locale)`, `DateFormat.yMd(locale)`, `DateFormat.Hm(locale)`.
  Un motif `'dd/MM'` reste français en anglais américain.
- Dates relatives (« il y a 3 min ») : une clé ICU plurielle par unité.
- Nombres : `NumberFormat.decimalPattern(locale)`. Prix : la devise du magasin
  (`currencyCode`), formatée dans la langue (`NumberFormat.simpleCurrency(locale: locale, name: code)`).

## Le cœur ne parle pas, l'écran traduit

`lib/core` n'importe jamais `l10n`. Il renvoie des **types** et des **codes** :

- Libellés métier (dénomination, cacheroute, catégories de signalement…) : le
  cœur normalise la valeur vers un `enum` ou un identifiant stable ; la couche
  présentation porte `extension XLabel on X { String label(AppLocalizations l10n) }`
  (dans `lib/presentation/features/<feature>/l10n/`).
- Erreurs d'API : `ApiResponse.errorKind` (délai, réseau, 401, 403, 404, 409,
  413, 429, 400/422, 5xx) et `ApiResponse.errorCode` (code stable du serveur,
  ex. `not_matched`). L'écran affiche `apiErrorText(context.l10n, response.errorKind)`
  (`lib/presentation/common/l10n/api_error_text.dart`) ou une phrase propre à
  l'écran choisie sur ce type ou ce code. **`ApiResponse.error` ne s'affiche
  jamais** : c'est un diagnostic pour le journal. Même règle pour `'Erreur: $e'`.

## De droite à gauche (hébreu)

Flutter retourne la mise en page tout seul si le code parle en `start`/`end` :

| au lieu de | utiliser |
|---|---|
| `EdgeInsets.only(left:)`, `fromLTRB` asymétrique | `EdgeInsetsDirectional.only(start:)`, `fromSTEB` |
| `Alignment.centerLeft` / `topRight`… | `AlignmentDirectional.centerStart` / `topEnd`… |
| `Positioned(left:)` | `PositionedDirectional(start:)` |
| `TextAlign.left` / `right` | `TextAlign.start` / `end` |
| `BorderRadius.only(topLeft:)` asymétrique | `BorderRadiusDirectional.only(topStart:)` |
| `Icon(LucideIcons.chevronRight)`, `arrowLeft`… | `DirectionalIcon(LucideIcons.chevronRight)` |

Les marges symétriques (`EdgeInsets.all`, `symmetric`) ne changent pas.
`Icons.arrow_back` de Material se retourne déjà ; les icônes Lucide non.

**Ne se retournent PAS** : les gestes de balayage de `SwipeDeck` (droite = like
dans toutes les langues), les icônes qui ne montrent pas un sens (cœur, étoile,
lecture audio), les numéros de téléphone et les chiffres. Les bulles du chat se
retournent : les messages du membre passent à gauche, comme dans iMessage en
hébreu.

## Le design ne bouge pas

Les règles de la session design (`docs/design/CHAT.md`, `MOUVEMENT.md`) restent
la loi : on ne change ni taille, ni couleur, ni espacement pour faire tenir un
texte. Un texte qui déborde dans une langue se signale (l'anglais et le russe
sont souvent plus longs, l'hébreu plus court) ; on raccourcit d'abord la
traduction.

## Tests

- `test/l10n/arb_catalog_test.dart` : toutes les clés dans toutes les langues,
  mêmes paramètres, descriptions présentes, fichiers assemblés à jour, aucun secret.
- `test/l10n/hardcoded_strings_test.dart` : **cliquet** des textes encore écrits
  en dur dans `lib/presentation` et `lib/core` (hors `lib/core/dev`). La liste
  `test/l10n/hardcoded_strings_baseline.txt` ne peut que rétrécir :
  ```bash
  UPDATE_L10N_BASELINE=1 flutter test test/l10n/hardcoded_strings_test.dart
  ```
  Un littéral qui ne s'affiche jamais (journal, motif de détection) va dans
  `_notUserFacing`, avec sa raison.
- Les tests d'écran tournent en français (`kTestLocale`) ; `pumpLocalized`
  (`test/helpers/l10n_helpers.dart`) rend un écran dans une autre langue, clair
  ou sombre, à 360 px de large : un débordement fait échouer le test.
