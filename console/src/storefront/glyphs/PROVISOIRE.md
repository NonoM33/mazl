# Glyphes provisoires

Ces onze SVG (`heart`, `two_hearts`, `pomegranate`, `flame`, `fir`, `sparkle`, `mask`,
`matzah`, `flower`, `sun`, `bolt`) sont des **dessins provisoires très simples**, écrits
pour que la console et la maquette fonctionnent avant la livraison des vrais glyphes.

Les vrais (viewBox 0 0 24 24, traits 1.75, `currentColor`) viennent de
`mobile/assets/storefront/glyphs/` et sont copiés ici par
`mobile/tool/app_icon/make_app_icon.py`. **Ils remplacent ces fichiers à la fusion**,
sous les mêmes noms : le code de la console n'a rien à changer. Supprimer ce fichier alors.
